User is a researcher working on PHNN (Port-Hamiltonian Neural Networks) for DC-DC buck converter characterization and controller design. The project targets publishable results, not just working code. Deep familiarity with PyTorch, power electronics (averaged PH model, PLECS simulation), and ML training pipelines. PLECS is used as the ground-truth switched simulator via XML-RPC. Research uses a GPU conda environment (`nilm-gpu`).
